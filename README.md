# Airbnb Data Project

Project layout:

- `data/raw/` - source CSV files
- `data/dictionaries/` - data dictionary CSV files
- `reports/` - Power BI report files
- `docs/` - exported documentation and PDFs

Current files:

- `data/raw/Listings.csv`
- `data/raw/Reviews.csv`
- `data/dictionaries/Listings_data_dictionary.csv`
- `data/dictionaries/Reviews_data_dictionary.csv`
- `reports/airbnb.pbix`
- `docs/airbnb.pdf`

## Dashboard Preview

To show dashboard images in this README, place the image files in a folder such as `docs/images/` and use Markdown image syntax:

```md
![Dashboard overview](docs/images/dashboard-overview.png)
```

If you want multiple screenshots, add one line per image:

```md
![Listings dashboard](docs/images/listings-dashboard.png)
![Reviews dashboard](docs/images/reviews-dashboard.png)
```
